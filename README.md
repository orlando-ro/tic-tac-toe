# Tic Tac Toe Monochrome

A minimalist, peer-to-peer Tic Tac Toe game featuring a sleek monochrome AMOLED dark theme.

## ✨ Features

- **Peer-to-Peer Connectivity**: Play with friends in real-time using PeerJS, removing the need for a dedicated game server.
- **AMOLED Dark Aesthetic**: A high-contrast, monochrome design optimized for OLED screens, featuring a technical grid background and glowing accents.
- **Seamless Invites**: Quickly share your Connection ID or a direct invite link to start a match.
- **Responsive Design**: Fully playable across different screen sizes.

## 🚀 Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Networking**: [PeerJS](https://peerjs.com/)
- **Typography**: Plus Jakarta Sans

## 🎮 How to Play

1. **Launch the App**: Open `index.html` in any modern web browser.
2. **Start a Match**:
   - **Host**: Copy your **Connection ID** or **Invite Link** and send it to your opponent.
   - **Join**: Enter your friend's ID in the input field and click **Join Match**, or simply click an invite link.
3. **Gameplay**: 
   - The first player to connect is typically 'X'.
   - Take turns marking the grid.
   - The first to get three in a row wins!

## 🛠️ Installation

Since this is a client-side application, no installation is required. You can simply serve the files using any local web server or open `index.html` directly.

```bash
# Example using serve
npx serve .
```
